# Security Policy

## Supported Versions
Only the latest release on the `main` branch is actively supported with security patches.

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a Vulnerability
If you discover a security vulnerability or secret leakage, please do not file a public issue.
Instead, email `techamit109@gmail.com`. You will receive a response within 48 hours.
